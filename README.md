# Jivanamrita 🌱🇮🇳

**Jivanamrita** is a digital platform built to empower farmers across India with tools for managing farm activities and connecting with agricultural experts and consumers. One of its key features includes **farm tour scheduling**, enabling stakeholders to directly visit farms, understand practices, and foster transparent supply chains.

---

## 🚀 Features

- 🗓️ **Farm Tour Scheduling**: Users can view and book tours across various Indian regions.
- 🌾 **Farmer Profiles**: Showcase farm details, products, and sustainable practices.
- 📍 **Location-Based Search**: Discover farms by state, crop, or farming method.
- 📸 **Media Support**: Upload images/videos of farm activities and products.
- 🔒 **Authentication**: Secure access for farmers, buyers, and visitors.

---

## 🛠️ Tech Stack

- **Frontend**: React js , Material UI
- **Backend**: Node.js
- **Database**: Firebase Firestore / MongoDB
- **Authentication**: Firebase Auth / JWT-based system
